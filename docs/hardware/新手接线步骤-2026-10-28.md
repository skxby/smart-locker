# 新手接线步骤

## 用什么线

“信号线”“地线”描述用途，不是要买的特殊线。桌面调试可用已有40P、20cm母对母杜邦线：彩色排线可以一根根分开，两头都是黑色小方头、端面有孔，套在电路板凸出的金属针上。公头则有露出的金属针；不能把公头松插进未焊排针的PCB孔当作可靠连接。

| 连接场景 | 实际线材/端头 |
|---|---|
| MCU两侧已焊排针 ↔ RC522排针 | 7根母对母杜邦线，优先短于或等于20cm |
| ST-LINK ↔ MCU调试排针 | 焊好兼容调试排针后用3根母对母杜邦线，可另加1根复位线 |
| USB串口模块 ↔ MCU排针 | 2根母对母杜邦线即可收日志 |
| MCU排针 ↔ MOS螺丝端子PWM/GND | 母头对剥皮线端的绝缘软线；可用已有杜邦线剪掉一头制备，剪断及剥线均先断电。这两根只走小电流控制 |
| 12V电源、保险座、MOS电源/输出、锁 | 已购22AWG红黑铜软线，约0.33mm²；螺丝端子端剥皮或压合适管形端头，不用杜邦线。最终载流/保险选择还需锁额定与实际电流 |
| 门磁/微动自带引线 ↔ MCU | 自带线末端压接母杜邦端子，或与母头线焊接并热缩绝缘；不裸绞、不用胶带代替可靠接头 |
| PC ↔ STM32 Type-C | 成品USB数据线，插USB插座，不能插到GPIO排针 |
| 相机 ↔ RK USB HOST | 相机原配成品USB线，不能猜裸板4个焊孔的顺序 |

颜色只是方便认线，建议电源正极红、GND黑；没有对应颜色可以用其他颜色并贴标签，功能由接的针决定。每个杜邦母头只插一根针，不能往一个孔塞两根线。多个模块共用3V3/GND时用正式焊接分配排针/端子，不裸绞成一团。

## 先做RC522七根线

拔掉STM32、ST-LINK、串口模块USB及12V电源后接线。STM32用背面彩色丝印找对应侧边金属针；B12就是PB12，E3就是PE3，不是“第12脚/第3脚”。双排每行有两根针，核清内外列再插。

| 拿一根母对母杜邦线 | 一头套在STM32标字对应针 | 另一头套在RC522对应针 |
|---|---|---|
| 红，电源 | 3V3 | 3.3V |
| 黑，地 | GND | GND |
| 白，片选 | B12 / PB12 | SDA |
| 黄，时钟 | B13 / PB13 | SCK |
| 绿，接收 | B14 / PB14 | MISO |
| 蓝，发送 | B15 / PB15 | MOSI |
| 紫，复位 | E3 / PE3 | RST |

RC522的IRQ不接。先单独给MCU Type-C供电实测3V3，再断电连接RC522，核对无误后供电。RC522不接5V/12V。接好只代表线束准备完毕，读卡仍需固件验证。

## 下载器与日志口：先处理未焊的接口

2026-10-28主板正面照片中，下端缺口处印着RST、3V3、DIO、CLK、GND，调试接口看起来未焊排针，不能直接套杜邦线。官方也注明天空星调试口为未焊接2×5P接口。先准备适配天空星调试接口的排针，按官方装配方式焊接并做通断/相邻短路检查；未焊接前不要硬插、手扶导线或用鳄鱼夹跨夹焊盘。初学者可请有焊接经验的人完成此处。

焊好后，按接口信号名连接，不凭照片朝向或单排字推两排针序：

| 母对母杜邦线 | ST-LINK端 | MCU调试接口端 |
|---|---|---|
| 黄 | SWCLK | CLK（H1-03） |
| 蓝 | SWDIO | DIO（H1-05） |
| 黑 | GND | GND（H1-04或06） |
| 白，可选 | RST | RST（H1-09） |

ST-LINK的SWIM不接STM32。主板由Type-C供电，ST-LINK的3V3/5V全部留空。先接好再上电，不自动烧录覆盖当前程序。

项目默认日志线是 MCU PA9/TX（H1-10）→模块RX、MCU GND→模块GND。用户当前实接改为 **MCU B10/PB10（USART3_TX）→模块RX**、MCU GND→模块GND；STM32引脚图将PB10标为USART3_TX，因此硬件走线方向正确。该更换必须由固件把日志UART配置到USART3、AF7、PB10后才会输出；项目当前文档/固件默认PA9，尚不能声称PB10已实测有日志。PB10不与项目选定的PD5/PD6 USART2柜控串口冲突，但USART3仍需在最终资源配置中正式登记。模块VCC及TX留空即可单向收日志；需要发数据到MCU时，先测模块TX空闲电平，再接TX→PA10或其他已配置RX。ST-LINK和日志模块都是连接PC的调试工具，不是RK与MCU正式业务通信线。

## MOS：本轮只准备控制线

新照片正面可辨型号YYNMOS-1，左边两位端子标PWM（上）、GND（下）。右侧四个功率端子须翻背面按DC−/DC+/OUT+/OUT−逐个对位，不能把背面上下左右直接复制到正面。

| 线材 | MCU端 | MOS端 |
|---|---|---|
| 母头对剥皮线端，黄 | B6 / PB6 | PWM螺丝端子 |
| 母头对剥皮线端，黑 | GND | 信号GND螺丝端子 |

线端只剥到足够进入端子，夹紧铜芯，外面无裸铜/散丝，轻拉不松；不能夹绝缘皮。MOS端PWM与信号GND间需正式安装10k下拉，不能把电阻脚松塞在杜邦母头里。模块3.3V触发兼容性、默认关断和硬截止仍待实测。

12V和锁本轮保持脱离。将来功率线功能对应：电源正极→保险座→DC+，电源负极→DC−，OUT+→锁正，OUT−→锁负；保护电容/二极管、共地/采样支路和保险额定按正式图册施工，此处不是允许直接通电的简化替代。OUT−不能另接GND/DC−，否则会绕过开关。

## 其他器件

| 器件 | 线材与目标 | 仍需处理 |
|---|---|---|
| 门磁 | 自带两根线，一根接E0/PE0，一根接GND，无极性 | PE0与3V3之间安装10k上拉；先测磁铁靠近/远离的通断 |
| 微动 | 自带线，NO接E1/PE1、COM接GND | PE1与3V3之间安装10k上拉；两线款先确认松开断、按下通 |
| 蜂鸣器 | 3根母对母候选：I/O→E2/PE2，GND→GND，VCC→匹配电源 | 照片只确认高电平触发；未核供电规格前VCC不接，不擅接5V |
| ADuM隔离板 | 两侧各4根小电流线，排针之间可用母对母 | 芯片型号及排针映射未核，暂不接；两侧地不跨接 |
| ADC分压 | 电阻/电容在洞洞板正式焊接，输出到C0/PC0 | 不是12V直接接PC0；分压和掉电注入未验，PC0先留空 |

蜂鸣器模块照片标有GND、I/O、VCC并标示高电平触发，BOM候选规格为3.3–5V。确认实物与该规格一致后，可用母对母杜邦线将E2/PE2→I/O、GND→GND、3V3→VCC；若模块不是该SKU、丝印不一致或尚未确认供电规格，VCC先不接。

## RK当前可确认的信息

通过SecureCRT屏幕只读观察到：窗口Serial-COM7，状态栏COM7/1500000，Linux提示符root@RK356X:/gec_yay#，启动输出含dropbear sshd和1024×600 framebuffer。证明系统已启动、现有控制台可用；未读取设备树或核实精确板型、UART物理针号及IO电压。

本轮没有在SecureCRT内输入命令、修改系统或占用COM7。用户提供的粤嵌手册与原理图已定位业务串口候选UART4/J703：1=GND、2=RX、3=TX、4=3V3，详见[板型与UART核对](RK3568板型与UART核对.md)。这些是逻辑针号，实物方向、系统复用和隔离板排针映射仍待核实；RK与MCU正式UART先不插线，保留当前控制台。
