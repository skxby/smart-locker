# 器件到货检测与确认

当前逐件清点未完成。用户确认A板12V输入去耦与B板PC0分压滤波所需的两只100nF均没有，A板470µF/25V已接好；未按正式电路补齐和核对前不接通MOS的12V或PC0采样线。实际型号、数量、版本、成交成本和功能均待逐件核对；“到货”不等于“验收通过”。填写[本批记录](../evidence/hardware-receipt-2026-10-27/summary.md)，电气细节沿用[验证手册](接线验证操作与记录.md)及[14页图册](接线图册/接线图册.html)。当前产品卡进度以机器索引为准，本清点不启动额外产品任务卡。

## 第一次只做这些

准备万用表、绝缘桌垫/干燥非导电台面、螺丝刀、标签和手机。黑笔插COM、红笔插VΩ，先短接两表笔，认识仪表的通断提示。电阻/通断/二极管档只测断电、脱离其他电路的器件。板子不要放在电脑金属外壳上，导电防静电袋也不作为通电绝缘垫。

1. 所有器件先分开放，MOS、锁、RK串口、PC0采样线都不接。先核清型号和两面丝印，留整机与端子近照。
2. 只给12V成品适配器接市电，低压端不连任何负载。万用表DC V档，红笔接DC插头中心、黑笔接外圈；小心不跨接中心与外圈。正读数约12V才标中心为正；读负数说明极性相反，记录实际值。不要拆适配器市电外壳。
3. 拔掉适配器电源，把DC母头与适配器分离。通断档确认母头中心接哪根线、外圈接哪根线，再贴正负标签；不能只信红黑线颜色。
4. 门磁两线脱离MCU，用通断档量两线。磁铁靠近/离开各测，记录“闭合低阻/断开OL”和距离。采购候选要求磁铁靠近闭合；不符合时先登记型号差异，不能改软件假装符合。磁铁那一件不接线。
5. 微动两线脱离MCU，用通断档量两线。NO候选应松开断、按下通；三脚款按壳体标记确认COM/NO/NC并逐组测，不能猜位置。
6. 电阻焊前量10k、22k、100k，各挑所需数量并贴阻值。二极管档红笔无环A、黑笔有环K，1N4007正向常见0.5–0.8V，交换通常OL；以实际器件和仪表说明为准。
7. 目检电解标称470µF/25V，负极条纹对应负脚；瓷片104为100nF、无极性。容量需具备电容量档的仪表确认；普通通断档不能证明容量和耐压合格。
8. 单独给核心板接Type-C，保持其他外设和ST-LINK电源脚断开。核H1孔方向后，DC V黑笔H1-04，红笔H1-02应约3.3V；红笔H1-07应约5V。表笔不碰相邻针脚。只凭灯亮不能确认这两路电压。

## 第二轮：USB、下载器、相机与日志器

| 器件 | 单件怎么接、怎么测 | 能确认到哪一步 |
|---|---|---|
| 核心板USB DFU | 仅Type-C接PC，按BOOT0→复位→松BOOT0，设备管理器无黄色感叹号；工具只点连接 | 确认DFU枚举和通信，不能证明所有引脚或FreeRTOS工作 |
| ST-LINK V2 | 先独立插PC核枚举；板断电接SWCLK→H1-03、SWDIO→H1-05、GND→H1-04，可选NRST→H1-09，再给板Type-C供电 | Keil/SWD读到目标信息；调试端口ID不是精确SKU证明，还要核芯片丝印。克隆ST-LINK的3V3/5V先不接；正规VTref按说明接 |
| CH340日志器 | 先只接PC，找COM口；DC V红TXD黑GND，空闲电平应匹配3.3V输入。再将本适配器TXD和RXD短接，串口工具115200/8N1、无流控、关闭本地回显，发送`TEST123` | 短接收到原字符串，移去短接后不再回传，才证明环回路径。VCC不接MCU；无COM口先查本款芯片驱动 |
| USB UVC相机 | 使用随附成品线独立插Windows PC，允许相机应用访问后选新相机，看实时画面/移动物体 | 初筛到货相机、USB线与画面；PC能出图不证明RK格式/曝光/帧时间戳满足项目要求 |
| 补光灯 | 核5V标签后，用额定电流足够的独立USB充电口，开关测试，观察闪烁/发烫 | 初筛供电与开关；不与MCU 3V3相连。核USB充电头总输出，不假定1A可同时带全部负载 |
| RK与原配屏 | 先认板品牌/型号/版号，仅原配供电/屏线开机，记录系统与板号 | 板能开机不等于UART可接；在查清IO域之前不接ADuM另一侧 |

ST-LINK、DFU、CH340可以分别用，不要把两个软件同时占用同一个设备。环回只是适配器单件测试，临时短接线测完拆掉，不保留在正式线束。

## 第三轮：MOS与传感器供电，再做需要固件的功能

先拍清MOS与蜂鸣器正反面、端子字和SKU/额定参数，核对是否为3.3V输入、触发极性与供电一致。YYNMOS-1六个端子必须按实物丝印识别，不能用别版照片的上下顺序直接接电。

- **MOS**：真实锁保持脱离。确认输入额定和12V电源极性后，OUT+与OUT−间用10k电阻替代锁作小负载（12V约0.0144W），红笔OUT+、黑笔OUT−量DC电压；输入分别明确为0V和允许的3.3V，相对模块信号GND记录输出。手动切线必须断电，不能向未知GPIO倒灌。该方法不证明驱动真实锁的电流能力。OUT−不额外接DC−或MCU地。电路与测点见[09页](接线图册/09-电源到锁完整逐端子图.svg)、[14页](接线图册/14-万用表表笔接法放大.svg)。
- **分压板**：100k上臂、22k下臂、中点并100nF到地；PC0线先不接。红笔公共中点A，黑笔分压地B，输入12.00V理想约2.164V；用实际阻值与输入值核算。核VREF+和掉电注入之前不能当正式ADC方案验收，见[10页](接线图册/10-分压电阻电容焊点与测点.svg)。
- **ADuM1201**：断电核芯片为1201及模块排针到芯片的对应，逐侧核供电，GND1/GND2不跨接；两侧都需要匹配供电。不能靠通断量芯片输入到输出判断磁隔离信号通路是否良好。RK若为1.8V IO不直接接本方案，见[13页](接线图册/13-ADuM芯片方向与模块追线.svg)。
- **RC522、板载Flash**：核型号与3.3V供电后，分别需要SPI2读卡和板载SPI1读JEDEC的验证固件。万用表只能检查供电、断线与明显短接，不能确认SPI设备协议正常。Flash先只读，不擦原数据；RC522读卡成功还需实际UID/错误记录。
- **蜂鸣器**：带驱动模块先核VCC/IN/GND及3.3V兼容性，再验证输入高低对应响/停；裸两脚蜂鸣器不能当模块直接GPIO。未写驱动时不以板上指示灯代替响声/极性证据。
- **核心板FreeRTOS**：已有Env_hsi16用于基础调度环境验证，Env_hse8_168用于确认8MHz外部晶振方案。下载会覆盖所写Flash区域，先确定现有程序是否要保留，再按[环境说明](../../firmware/README.md)执行；Keil观察env_task_progress持续递增、env_fault保持0。Env_hsi16已在用户授权下烧录，任务计数、故障标志和HAL/RTOS时基实测见[上板记录](../evidence/environment-board-2026-10-28/summary.md)；未测HSE或外设功能。

## 锁最后验

到货先查12V额定、最长允许通电时间、线色/极性/内置保护、锁扣是否配齐和尾杆手动释放。断电测线圈电阻时读有限低阻可能正常，不能因通断鸣叫就判短路；不凭DCR猜允许脉宽或保险额定。

真实通电前必须已有MOS默认关闭和硬件截止的波形证据，再依据厂家规格设脉宽，在门打开、尾杆可操作条件下测试。不能把12V长期直连线圈试“响不响”，不能先随便插一根3A保险。1N4007有环K跨接LOCK+、无环A跨接LOCK−，还需核电流能力、内置保护与释放时序。

普通示波器通道地通常互通，不能夹OUT−或隔离两侧造成短接。MCU断电、12V仍在时，分压可能经PC0注入；单测MOS掉电先拔PC0线，整机掉电兼容另验。没有限流电源/差分探头等工具就记录对应项尚缺证据，不推定已通过。

## 怎样才叫确认

每件记录实物型号、数量、正反面/测点照片、工具和档位、实测值、预期、结论与异常。只有照片/页面参数的不写实测PASS；只有供电正常的不写功能PASS。裸板验证、单件测试和正式卡验收分开记录，profile保持UNVERIFIED直到其全部验收条件满足。
