# 照片接线核对

依据用户2026-10-28提供的首批8张及补充2张照片；仅目视识别，未测电压、通断或功能，不改变硬件profile的UNVERIFIED状态。电气方案沿用[引脚接线表](引脚确定与接线表.md)，施工按信号名找实际丝印，不从照片左右方向推针号。

| 照片 | 可见事实 | 接线结论 |
|---|---|---|
| 1 | ST-LINK V2外壳标签含SWCLK、SWDIO、GND、RST、3V3、5V | 可准备SWD三线；两路电源脚不接。标签方向须对应实物插针 |
| 2 | USB串口模块P2标GND/RX/TX/VCC，选择区有多个电压档 | 芯片型号和实际TX电平不能只凭照片确认；MCU已有USB供电时VCC不接。跳帽位置不构成3.3V IO实测证据 |
| 3 | 功率模块背面可见DC−/DC+/OUT+/OUT−与PWM/GND标字 | 补充正面确认YYNMOS-1、PWM/GND控制端；额定参数及3.3V兼容性仍待核，暂不接12V和锁 |
| 4 | 蜂鸣器模块标GND、I/O、VCC及高电平触发 | 可识别触发标识，但VCC额定/3.3V兼容性尚需SKU或说明确认 |
| 5 | RFID-RC522 V1.3，排针标SDA/SCK/MOSI/MISO/IRQ/GND/RST/3.3V | 可按下表准备SPI2线束，供电3.3V；SDA在本项目SPI接法中为片选 |
| 6 | 隔离小板可见V1/A0/B1/G1等标字及另一侧标字 | 芯片完整丝印、顶视方向、模块到芯片映射尚未核清，不给逐排针接法，不跨接两侧地 |
| 7 | 裸相机板上有4个焊孔，照片未展示完整USB线缆与型号 | 不推断焊孔排列；用厂家成品线先接PC验证USB枚举和画面，之后接RK USB HOST |
| 8 | 天空星板背面排针丝印和已连接的Type-C | 补充正面可见调试接口RST/3V3/DIO/CLK/GND，接口看起来未焊排针；芯片完整丝印/晶振仍未读清 |

详细线材、母头/剥线端说明、未焊调试口处理及SecureCRT观察见[新手接线步骤](新手接线步骤-2026-10-28.md)。

## 可准备的低压信号线

全部断电时接线。下列是项目候选分配；先在实物确认GPIO丝印和连接器方向，再插针。不要按线色推信号。

| 模块端 | MCU端 |
|---|---|
| ST-LINK SWCLK | PA14 |
| ST-LINK SWDIO | PA13 |
| ST-LINK GND | GND |
| ST-LINK RST，可选 | NRST |
| USB串口 RX | PA9，MCU日志TX |
| USB串口 GND | GND |
| USB串口 TX，可选 | PA10；只有测得3.3V兼容电平后才接 |
| RC522 SDA | PB12 |
| RC522 SCK | PB13 |
| RC522 MISO | PB14 |
| RC522 MOSI | PB15 |
| RC522 RST | PE3 |
| RC522 3.3V / GND | MCU 3V3 / GND |
| RC522 IRQ | 留空 |

主板先仅用Type-C供电，ST-LINK的3V3/5V及USB串口VCC均留空。RC522接入前实测3V3供电；连接后能否读UID仍需驱动和实测。USB串口只接RX/GND即可收日志，不必为了收日志连接TX。

## 尚缺的安装输入

主芯片清晰丝印、调试排针焊接核查；MOS额定参数；隔离板两面清晰近照；蜂鸣器供电规格；相机型号及随附成品线；RK板型/串口IO域；锁标签/允许脉宽和电源保护信息。3V3、串口TX空闲电压和12V极性仍需万用表测量。照片里没有门磁、微动、锁与保护件，不能确认其安装和接法。

真实锁保持断开，直到MOS默认关闭、厂家允许脉宽与硬件截止得到验证；OUT−不得额外接DC−或地。ADuM1201每侧要求2.7–5.5V供电，不能直接套用1.8V RK IO。
