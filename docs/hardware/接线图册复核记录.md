## 发现与处理

| 问题 | 处理与边界 |
|---|---|
| 原图的元件连接主要靠文字，公共焊点与两条引脚不直观 | 新增09电源锁回路、10分压公共节点、11触点上拉、12元件极性/分支、13隔离芯片顶视、14表笔落点 |
| 查看器缩小整张图后难辨细节 | 保留3200×2240 PNG和SVG；增加150%/200%放大与横向滚动入口 |
| MCU断电而12V仍在时，ADC可能受分压节点注入电流 | 独立验证MOS掉电默认态前拔PC0线，断开其他可能倒供的信号源；整机掉电兼容继续未验证，不能由此独立测试推定整机安全。必要保护/时序需后续设计、测试与预算评估 |
| 商品模块的外形图可能被误当通用针序 | MOS图明确按用户照片对应、到货核版次；ADuM顶视图明确区分芯片脚号与模块排针；没有给未知RK板猜针号 |
| 二极管色环和电解负极条纹容易混淆 | 第12页分别标：二极管有环K接LOCK+，电解负极条纹接12V−入口 |
| 节点分支与文字挤在一起 | 新图调整标签位置，补分支实心圆点，避免以导线交叉表达不清的连接 |
