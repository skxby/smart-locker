## MCU候选分配

P1/P2为官方原理图左右连接器名，不等于当前手持实物方向；先找丝印、1脚、方焊盘，再数孔。每行奇偶号见第02页，未用孔不接。

| 用途 | GPIO / 外设 | 孔位 | 终点 |
|---|---|---|---|
| 锁控制 | PB6 / TIM4_CH1 AF2 | P2-23 | MOS PWM；确认高有效后10k下拉到模块GND |
| 门磁 | PE0 / EXTI0 | P2-19 | 触点一端；另一端GND；10k上拉3V3 |
| 微动 | PE1 / EXTI1 | P2-18 | NO；COM到GND；10k上拉3V3 |
| 蜂鸣 | PE2 / GPIO | P2-13 | 带驱动模块IN，候选3.3V供电 |
| RC522时钟 | PB13 / SPI2_SCK AF5 | P1-25 | SCK |
| RC522接收 | PB14 / SPI2_MISO AF5 | P1-28 | MISO |
| RC522发送 | PB15 / SPI2_MOSI AF5 | P1-27 | MOSI |
| RC522片选 | PB12 / GPIO | P1-26 | SDA/SS/NSS，SPI模式为CS |
| RC522复位 | PE3 / GPIO | P2-12 | RST；IRQ不接 |
| 电压采样 | PC0 / ADC123_IN10 | P2-14 | 100k/22k节点，并100nF到地 |
| RK发送 | PD5 / USART2_TX AF7 | P2-29 | ADuM1201芯片3 VIB |
| RK接收 | PD6 / USART2_RX AF7 | P2-28 | ADuM1201芯片2 VOA |
| 日志发送 | PA9 / USART1_TX AF7 | H1-10 | CH340 RXD |
| 日志接收，可选 | PA10 / USART1_RX AF7 | H1-08 | CH340 TXD，先确认真正3.3V IO |
| SWD | PA14 / PA13 / NRST | H1-03 / 05 / 09 | SWCLK / SWDIO / NRST |
| 普通地 | GND | H1-04/06、P1-39、P2-37/39 | 低电流分配点 |
| 3.3V | 3V3 | H1-02、P1-38、P2-38 | 匹配低电流模块，核LDO总负载 |

板载Flash为SPI1：PA4=CS、PA5=SCK、PA6=MISO、PA7=MOSI，不加飞线；型号/容量须读JEDEC核实。RC522单独用SPI2。TIM6归HAL tick；SysTick/SVC/PendSV归FreeRTOS。PA0按键、PB2 LED/BOOT1、PA11/12 USB、PA13/14 SWD、TF/晶振/参考电压不挪用。UART DMA和SPI速率实施时另核资源与时序，本图不代表已配置。

## 连接边界

- MOS DC±是电源，OUT±接锁。OUT−不得额外接DC−或地，否则低边开关被绕过。续流二极管跨锁：有环K接LOCK+，无环A接LOCK−；实物锁若内置保护，先核厂家接法。
- 照片背面标字对应到正面：左上PWM/左下GND；右侧自上到下DC−、DC+、OUT+、OUT−。第04页按此照片画，到货须核同版次。正反面不能照抄左右。
- 新增09–14页放大细节：功率回路的电气节点、分压的四端公共点、触点上拉、元件极性、ADuM顶视图、表笔落点。图册支持150%/200%放大与横向滚动。
- 12V持续而MCU失电时，分压节点可能向PC0注入电流；单独验证MOS掉电默认态时须先拔PC0采样线。这不证明整机掉电兼容，保护与时序仍未验证。
- 为分压采样，12V−和MCU GND在入口单点相连，两者不隔离。ADuM两侧各用本域电源和地，不跨接；USB/探头等回路也可能绕过隔离。
- ADuM1201芯片：1 VDD1、2 VOA、3 VIB、4 GND1、5 GND2、6 VOB、7 VIA、8 VDD2。商品模块排针不能套芯片顺序，断电追线确认；ADuM1200方向不同。
- RK板型未知，UART物理孔号、IO电压、复用、设备节点和电源口待核。图中RK端是功能名，不是插线针号。若IO是1.8V不能接ADuM1201，需另匹配、重新核价。
- 相机接RK USB HOST；补光接独立5V USB口；RK和屏用原配电源/线。灯与MCU不可通过未经核额定的USB分线器共用电源。
- 未量柜体和模块安装孔，不给出虚构钻孔坐标、裁板尺寸和线长。
