# RK3568板型与UART核对

## 资料基线

2026-10-28用户提供的粤嵌RK3568硬件手册（2023年08月）、底板V10原理图、核心板V10原理图及底板装配图是本次板级设计依据。资料路径在用户桌面：`3-三阶段/1-交叉开发/3. 资料/1-RK3568资料/`。手册第7页描述粤嵌核心板、底板、屏幕三层结构；实物版本与资料一致性仍需核对。

本次只读PDF并目视核对底板原理图第8页，没有烧写系统、修改设备树、改变SecureCRT或占用COM7。硬件profile保持UNVERIFIED，产品卡状态不变。

## 项目业务串口候选：UART4 / J703

硬件手册第10–11页将UART0/1/3/4外部接口标为3.3V，DEBUG口则是UART2经CH340转换的USB接口。底板原理图第8页J703标注UART4，TX/RX分别经R714/R715（100Ω）引出，管脚如下：

| J703逻辑针号 | 功能 | 项目用途 |
|---|---|---|
| 1 | GND | ADuM隔离板RK侧GND2 |
| 2 | UART4_RX_M1 | 接隔离板RK侧输出VOB，ADuM1201芯片6脚 |
| 3 | UART4_TX_M1 | 接隔离板RK侧输入VIA，ADuM1201芯片7脚 |
| 4 | VCC_3V3 | 隔离板RK侧VDD2候选电源，ADuM1201芯片8脚；先实测 |

这些是原理图针号，不是面对实物的左右顺序。施工前找到实物J703/UART4与1脚标记，断电核GND，并通电单独测4对1的电压；不盲数“左起第几个”。模块到芯片排针映射尚未核实，不能直接按芯片脚号往商品小板排针插线。

核心板资料中的UART4_M1复用为GPIO3_B2/TX、GPIO3_B1/RX，底板也引至音频阵列连接器；实际启用前须排查设备树/pinctrl和当前驱动占用。不因有连接器就断言系统已启用UART4。

## 两侧连接关系与线材

| STM32侧 | ADuM1201芯片信号 | RK侧 |
|---|---|---|
| PD5 / USART2_TX → VIB（3脚） | 隔离后由VOB（6脚）输出 | → J703-2 / RX |
| PD6 / USART2_RX ← VOA（2脚） | 隔离前由VIA（7脚）输入 | ← J703-3 / TX |
| STM32 3V3、GND | VDD1（1脚）、GND1（4脚） | 不接到RK侧 |
| 不接到STM32侧 | VDD2（8脚）、GND2（5脚） | J703-4 / 3V3、J703-1 / GND |

两边都是小电流线。两端都有已焊金属排针时用已有20cm母对母杜邦线；如果实物是插座，需要匹配其间距/端子制式，不强塞杜邦头。两侧电源各取本侧，GND1/GND2不跨接；现有PC、USB和测量仪器可能形成额外接地路径，验收隔离时一并检查。正式方案保留ADuM隔离，不因标称同为3.3V擅自省掉。

## 保留与避让

- DEBUG/UART2继续用于现有SecureCRT，不作为柜控UART，也不拔除现有控制台线。
- UART3/J704与CAN共享内部IO，使用需匹配S300拨码及复用，本项目优先不选它。
- UART1/J702外部标称3.3V，但第8页有Q700/D718电平适配，不能把外部连接器电压等同所有SoC引脚的电压。
- 相机使用USB HOST及原配线，补光保留独立5V供电；硬件手册给出3个USB2.0口合计0.5A、USB3.0口0.5A的限制，实际相机功耗仍需核对。
- 原配RK供电继续保留，不从MCU或隔离板给RK主板供电，不重烧系统来“试串口”。
