# 保护与分压小板布局

状态：候选设计，未实物验证。施工入口：[图册04页](接线图册/04-MOS锁回路与分压.svg)、[06页](接线图册/06-小板元件脚与安装.svg)、[验证操作](接线验证操作与记录.md)。

电气焊点放大见[第10页](接线图册/10-分压电阻电容焊点与测点.svg)及[第12页](接线图册/12-元件两脚与焊接分支放大.svg)，图中节点不是未测的实际孔位。

两片3×7cm洞洞板先保留原尺寸。未测模块尺寸、端子脚距与安装孔，不提供固定行列焊接坐标。先摆实物、试插、标孔、再焊。KF301脚距5.0mm，与2.54mm网格不完全相同，不强塞。

MOS自身已有螺丝端子，独立绝缘固定在小板旁，不当作排针模块插拔，不焊死在洞洞板。电解与散热件不叠放。保险座串在12V正线入口，靠近连接器，额定电流按实测与保险曲线确定，不按3A占位施工。

| 位置 | 元件与网络 |
|---|---|
| A板输入 | 保险后12V+、12V−端子 |
| A板中部 | 470µF/25V与100nF并联于输入；电解负极条纹端到12V− |
| A板输出 | 到MOS DC±的端子；功率线用22AWG铜软线 |
| 入口地分支 | MCU/分压地单独回12V−入口，避免共用锁回流线段 |
| B板 | 12V+→100k→ADC节点→22k→GND；节点并100nF到GND |
| B板低电流区 | 3V3/GND分配点；PE0/PE1各经10k上拉3V3 |
| MOS输入附近 | 确认高有效后，PWM经10k下拉到模块GND |
| 锁体端 | 1N4007跨线圈，有环K到LOCK+、无环A到LOCK−，两焊点各自绝缘 |

OUT−/LOCK−不额外接DC−/GND。不能用地汇流绕过开关或隔离两侧。1N4007的实际适用性须核锁电流、释放时间与内置保护。

焊接顺序：电阻/瓷片→排针/端子→电解。洞洞板相邻孔默认不相连，用铜导线连同网，焊锡不能作功率导线。裸剪脚只用于核过材料和尺寸的短低电流跳线，不能由封装推定线径/铜材。对外锁回路不用杜邦线。

分配点用多个焊接排针并网，一孔一线，不把多根线硬塞杜邦孔。线头正确压接或焊接热缩绝缘，端子内无散丝、不能夹到绝缘皮；固定后轻拉。尼龙柱架空底部焊点，背面相对元件面左右镜像，焊前追线。锁和微动用刚性支撑，不以胶粘纸箱承力。

通断/电阻/二极管档只在断电并释放电容后用。线圈、电容充电和模块保护器件可能造成鸣叫，不能以“锁两端必须开路”验收。先脱离负载逐网查，再分级上电。没有限流电源不声称完成限流测试；保险不代替限流或硬截止。

安装尺寸、最终线长和辅料复用条件需到货确认，不足时报告预算，不暗加采购。
