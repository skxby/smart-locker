# 淘宝手动核对关键词

用途：淘宝对自动化访问做了限制，这份表供你手动搜索、核对规格与价格后回填 `config/materials/selected-bom.json`。
搜索时把“关键词”整行粘进淘宝搜索框；判定要点写的是**必须满足的硬条件**，不满足就不要选。

参考价＝当前清单金额（淘宝页面价或京东页面价），只作比价基准，不是结算价。

## 5. 回填方式

核对完把「商品 id + skuId + 页面价 + 你选的规格名」发我，我写回 `selected-bom.json` 并重算总额。
判定口径不变：规格不符就标 `SPEC_MISMATCH`，参数没核到就标 `SKU_OK_SPEC_TODO`，不拿“看着差不多”的款充数。
