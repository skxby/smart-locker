# S2-05 空载脉冲与硬截止波形记录

日期：2026-10-30。目标板：STM32F407VGTx（天空星），ST-LINK/V2 三线 SWD。
条件：锁线圈、MOS、12V、PB6→MOS 信号线**全部断开**，PB6 只接示波器探头（10X、直流耦合、地夹接 MCU GND）。

镜像：`build/firmware-s205-cutoff-gnu/hse8_168/locker_s205-cutoff.hex`（10100 B，只占第0扇区），
编译器 xPack GNU Arm Embedded 15.2.1，HSE 8 MHz→168 MHz。板载运行确认见 `program.json`。

## 触发方式

`cutoff_validation.c` 提供只由 Control 任务消费的 SWD 邮箱（`cutoff_command` / `cutoff_pulse_ms`），
每条命令执行一次，不自动重复。工具入口 `flash-and-trigger.py`，需 `--program` 或显式 `--trigger`。

## 五组结果

照片：`photo-normal-1000ms-500msdiv.jpg`（500 ms/格，正脉宽读数 1.00 s，游标 3.300 V，峰峰 3.76 V）、
`photo-reset-edge-100us.jpg`（100 µs/格落沿）。

| 组 | 命令 | 冻结条件 | 期望 | 实测（示波器） | 邮箱读回 |
|---|---|---|---|---|---|
| 1 | 1000 ms | 无 | 3.3 V、1 s、回零 | 3.3 V / 2 格 @500 ms/格 / 落沿干净 / 保持低 | count 0→1→2→3，result OK，fault 0 |
| 2 | 50 ms | `__disable_irq()` 后自旋 | 仍 50 ms 结束 | 2.5 格 @20 ms/格 | count 3→4，读回 `phase=2`（当时仍在关中断自旋） |
| 3 | 50 ms | `vTaskSuspendAll()` 后自旋 | 仍 50 ms 结束 | 2.5 格 | count 4→5，读回 `phase=3`，调度器恢复后 progress 继续 |
| 4 | 1000 ms | 50 ms 时 `board_lock_off()` | 提前截断在 50 ms | 2.5 格 | count 0→1，MODER 回到 0x1280（GPIO 输出），未复位 |
| 5 | 1000 ms | 50 ms 时 `NVIC_SystemReset()` | 截断 + 复位后保持低 | 2.5 格，之后 0 V | 读回 `phase=5`、MODER=0x280（复位默认），随后 count 归 0、progress 从 0 重新计数 |

电平读数：第 1 组高电平游标读 3.300 V，峰峰值 3.76 V，差值约 0.46 V 出现在边沿处，
属探头未做补偿校准与边沿过冲范围；不影响宽度与回零判据，但定量测量前应做探头补偿。

第 2、3 组的 `phase` 读回值是关键旁证：读回发生在脉冲结束约 0.9 s 后，此时 `phase` 仍停在 2/3，
说明该时刻 CPU 仍处在"中断全关"/"调度器全挂"的自旋中，即**发脉冲到脉冲结束的整个窗口内软件确实无法运行**，
脉冲仍在设定宽度自行结束。

第 5 组两次复现同一签名：读回瞬间 `gpio_b_moder=0x280`（PB3/PB4 回到复位后的 JTAG 默认复用）、
`phase=5` 未清；数秒后 `count=0`、`progress` 从小值重新累加、`MODER=0x1280`、`ODR=0`，
证明是真正的整片复位后重新启动，而不是软件把计数写回 0。

## 复位瞬态（100 µs/格，下降沿触发）

照片：`photo-reset-edge-100us.jpg`。时基 100 µs/格、10X、1.00 V/格、触发电平 1.50 V、下降沿、Single。

- 落沿陡直，未观察到缓慢斜坡；
- 落沿后 0.7 ms 窗口内稳定贴在 0 V 附近，波动约 0.07 格（≈70 mV 峰峰），属探头地线回路与底噪；
- **未见**中间电平平台、未见回升到逻辑阈值以上、未见振铃尖峰。

读数：峰峰值 3.52 V。高电平 3.52 V 略高于 3.3 V 标称，属探头未做补偿校准/上升沿过冲范围，未做定量结论。

结论边界：该结果只说明"在 100 µs/格分辨率下复位瞬间没有出现危险电平"，
不等于"复位瞬态绝对不存在"，也不替代真锁负载下的验证。

## 待确认

- MOS 端 PB6→GND 的 10 kΩ 下拉是否已实际安装。若已装，落沿后贴 0 V 可归因于下拉；
  若未装，则说明复位期间引脚未浮空或浮空时间短于观测分辨率，10 kΩ 下拉仍应按必装项处理。
- 本记录只覆盖空载（仅探头负载）条件；真锁线圈、12 V 与 MOS 接入后的行为未验证。
