# S2-02 后续待验与限制

| 项目 | 当前事实与关闭条件 | 归属 |
|---|---|---|
| PC0实物标定 | 用户明确授权后移；仍缺100nF或分压未完成，PC0不接、ADC资格=false。补齐保护/分压/基准后，记录ADC原始码、万用表毫伏、至少两个有效电压点及越界/故障路径；不得以compile-only分支冒充标定。完成前供电无效、不开真锁资格 | S2-02补证，须在S2-08基础门禁前关闭 |
| 外部上拉/安装 | 无内部上拉时PE0开路读值游移；启用内部上拉后连续开/闭复测通过，不能据此证明外部10k连接完好。安装时核外部10k、接头与门磁实际动作距离；两线触点仍不能诊断断线 | S2-07安装及S2-08核查 |
| 7/10字节实物卡 | 主机协议fixture通过；手边两张实物均4字节，无7/10实物证据，遇到样卡需补板上读卡。未新增采购或预算 | 后续硬件补证 |
| Flash真实busy | 本卡只读9F/05，不产生真实写/擦忙；代码每事务释放总线、并发/超时fixture通过。S2-04实际写/擦时补读卡延迟、忙期间总线释放/互斥记录 | S2-04 |
| 非NXP身份0x82 | 只确认该版模块配置回读和两卡实测；无卡可能产生空FIFO IO_ERROR，结果清空而非保留UID。不能把UID或模块版本当身份安全证明 | 后续Storage/健康装配按真实状态处理 |
| 真锁与截止 | PB6仍为输入，所有pulse拒绝；无真锁、复位瞬态或脉冲截止证据。当前采样脚本短暂停核，不能用来证明实时截止 | S2-05 |
