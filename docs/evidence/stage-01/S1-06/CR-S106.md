# S1-06 集成契约适配

| 项 | 决定 |
|---|---|
| 归属 | 当前会话兼任集成/契约负责人，统一修改真源、生成器和调用方 |
| C配置 | locker_core_config_t增加runtime_health_owned、device_simulated；内部调用方须重编，公开JSON/UART版本仍0.2.1 |
| 发送职责 | 正式Runtime设置runtime_health_owned=true并唯一发送HOST_HEALTH；零初始化false保留无Runtime库级fixture的原发送路径，不能在正式装配中启用两个发送者 |
| 来源 | device_simulated来自可信装配，公开Device及持久device_state保持相同来源，关闭CR-S104-1 |
| 状态投影 | 存在设备适配器时，Core完成DB恢复不等于设备READY；缺当前会话/快照时RECONCILING，其余跟随当前session.device_mode；工具可用性依该mode计算 |
| 生成 | scripts/build_contracts.py更新contracts/include/locker_contracts.h；不手改生成物 |
| 验证 | 正式service生命周期/字节流、运行健康样本、原Core/HTTP/IPC全量回归；实际结果见summary.md |

Runtime不向Core注入健康计数，也不从公共配置接纳设备/传感器状态。
