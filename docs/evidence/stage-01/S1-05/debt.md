# S1-05 非阻塞债务

| 项目 | 边界 / 建议 |
|---|---|
| RK/部署/硬件 | 当前只验证VMware Linux x86_64，RK ABI、实际TLS部署、手机UI和GPIO硬截止需各自后续卡；不能把模拟器证据当实物 |
| 原生接口重编 | receipt扩展改变内部C调用签名；所有调用方按生成头重编，不能把旧静态库与新头混用 |
| 行尾描述 | 基线有CRLF文件，与入口“全部LF”的历史描述不符。本卡保留已跟踪文件格式并使用cr-at-eol识别检查，避免整文件无意义diff；统一格式需独立维护变更 |
| 历史构建缓存 | 磁盘清理保留源码和日志，旧build已去除可重建二进制；不能直接当现成产品复用，复验用新目录。历史压缩归档按映射解包 |
